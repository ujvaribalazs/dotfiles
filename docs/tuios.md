│ Keys                │ Action                   │
├─────────────────────┼──────────────────────────┤

Selection
╭──────┬─────────────────────────────╮
│ Keys │ Action                      │
├──────┼─────────────────────────────┤
│ c    │ Copy selection to clipboard │
╰──────┴─────────────────────────────╯

Note: ctrl+b is the leader key. Press it followed by another key for prefix commands.
Set keybindings.leader_key to move it.                                               
`tuios keybinds unbind <action>` takes a key off one action.                         
`tuios keybinds free <key>` hands a key back to the program in the pane.             
Run `tuios keybinds doctor` for every scope, including the ones not listed here.
